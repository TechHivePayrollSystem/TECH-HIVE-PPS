# 🧾 TECH HIVE PAYROLL SYSTEM

Welcome to the **Tech Hive Payroll System** — a COBOL-based payroll management tool designed to simplify employee salary processing, tax calculations, and leave tracking. This system was developed as part of a learning initiative to explore legacy systems still in use in enterprise environments.

## 🚀 Features

- 🧑‍💼 **Employee Registration**  
- 📊 **Payroll Calculations** (Tax, Deductions, Bonuses)
- 📅 **Leave Management**  
- 🎂 **Birthday Bonuses**
- 🧾 **Payslip Generation**
- 💾 **File-Based Data Handling**

## 🛠️ Technologies Used

- 👨‍💻 **COBOL** — Main programming language  
- 🗃️ **Flat File Storage** (`.dat` / `.txt`)  
- 💻 **Linux Bash** for running and testing
